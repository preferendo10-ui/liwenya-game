# 合成李文亚

一个仿「合成大西瓜」的网页合成小游戏：把 11 张梗图一路合成到「李文亚」。两个李文亚相撞会融成不断膨胀的黑体生物；黑体贴墙后会转成竖向膨胀，玩家可以化成白体黏稠液体把它同化。

## 在线玩

- 正常游戏：https://preferendo10-ui.github.io/liwenya-game/
- 挑战演示：https://preferendo10-ui.github.io/liwenya-game/?demo=challenge
- 黑体场景：https://preferendo10-ui.github.io/liwenya-game/?demo=black
- 已化白场景：https://preferendo10-ui.github.io/liwenya-game/?demo=white

## 操作

- 鼠标：移动瞄准，点击投放。
- 触屏：拖动瞄准，松手投放。
- 键盘：`←` / `→` 微调，`空格` / `回车` 投放，`B` 化白 / 恢复，`R` 重开，`M` 静音。
- 两个相同图案相撞合成高一级；「奶奶」不会触发理论过载线。
- 黑体出现后点击「变成白体」或按 `B`，白体碰到已放置对象会溶解它，贴住黑体 4 秒完成同化。
